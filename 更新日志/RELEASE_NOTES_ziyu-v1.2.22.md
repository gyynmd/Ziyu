# 字域 1.2.22

## 用户更新

- 主页可以选择 OverlayFS、Magic Mount、元模块自动挂载或字域自挂载。OverlayFS 遇到设备不支持的目标时，会尝试兼容挂载方式。
- 恢复系统字体时，会同步撤回元模块目录中先前发布的旧字体，避免重启后还残留自定义字体。
- 导出日志时会一并带上挂载状态、字体路由验证结果和挂载运行日志，反馈挂载问题时不用再单独找文件。
- 修正字体导入入口对 WOFF/WOFF2 的拦截；导入后仍转换为系统可用的字体文件。
- 字体库管理中可以批量删除选中的字体 Family，并一并删除对应字重文件；如果删除当前使用的字体，会先准备恢复系统默认字体。
- 字体模块 ZIP 即使把字体放在多层目录中，也能识别并导入，不会把同名文件互相覆盖。
- 挂载模式变更需要完整重启后生效；App 会显示当前选择和本次启动的实际验证结果。
