# 字域 v1.2.27 — Debug 版

根据 `docs/MOUNT_FAILURE_DIAGNOSIS.md` 中 PLK110 / SukiSU / NoMount 的现场证据修复挂载救援。

- 自挂载遇到 ROM 符号链接槽位冲突或路由验证失败，完整回滚后立即尝试通过当前激活的 NoMount 接管。
- 保留各逻辑字体路径，不把不同度量变体合并成一个 ROM 实体文件；注入成功后必须通过 PID 1 哈希与字体路由验证。
- 救援失败允许后续启动阶段有限重试；service 最终失败写入明确失败状态。
- NoMount 救援规则写入本模块账本，软重启、默认字体恢复、禁用启动和卸载脚本按归属清理，不能确认清理时保留失败记录。
- 规则解析器去掉已被打包裁剪的 urllib 依赖，避免 NoMount 规则查询、注入验证和清理因缺少 Python 库而失败。

交付使用 Debug APK；编译和 ZIP 完整性检查不代表手机实测验收。
