# 字域 v1.3.4 — 本地 Debug 修复候选

- 减少 Vivo 多槽位生成中的重复工作：同一源字体、字重、变量保留策略和角色只准备一次。
- 相同字重的准备结果供不同 UI 槽位复用，各槽位的原厂度量继续分别处理。
- 保留中文/英文字符检查、源文件变化检查、真实字重、特殊字体保护、挂载校验和回滚。
- 生成结果记录 `preparedDonors`、`reusedDonors` 与阶段耗时，供手机日志对比。

本次修正的是源码中已确认的重复实例化路径。1.3.3 用户本次慢任务的进度和新日志尚未收到，不能据此断定全部耗时来自该路径。通用编译默认 90 秒预算与后续兼容处理保持原流程，不能把预算上限当成每次固定等待。

本地仅检查语法、Android 编译、签名和包完整性；未添加或运行行为测试，未安装、刷入或测量手机耗时。不承诺具体加速比例。
