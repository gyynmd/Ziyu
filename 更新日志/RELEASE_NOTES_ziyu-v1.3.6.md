# 字域 v1.3.6 — 本地 Debug 优化候选

- 合并挂载状态读取：启动钩子、挂载详情与设置查询按一次完整记录读取，减少反复读同一文件和启动外部命令。
- 挂载结果日志复用本次已提交的状态；每次新查询、启动钩子和成功提交均刷新读取，避免混合不同时间的字段。
- 状态按固定字段作为文字解析，兼容 CRLF、首个重复字段和字段内的等号；缺失或读取失败时清空快照，继续按待确认状态处理。
- 本次优化范围为状态读取；字体内容哈希、PID 1 路由验证和事务回滚仍按原执行路径运行。

检查范围：Shell 语法、Android 编译、APK 签名与模块包完整性。按项目规范未添加或运行行为测试，也没有手机安装、刷入或重启验收。实际启动、查询与字体切换耗时尚无同条件手机对比。
