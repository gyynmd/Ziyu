# 字域 v1.3.11（本地 Debug 删除体验调整候选）

- 字体卡片去掉三个点，点击卡片进入详情；底部「应用」旁直接放置「删除」。
- 确认删除后，所选卡片立即从字体库隐藏，数量同步更新；真实删除继续在后台执行。
- 删除状态移至通知和任务中心，字体库不再显示删除等待进度条。
- 删除失败时恢复未确认删除的字体，保留收藏和标签。批量部分成功会保留已确认的删除结果，再重新读取实际字体库。
- 待删除字体不会被旧的后台刷新重新显示；删除期间的重复刷新留到结束后合并处理。
- Material、Miuix、COUI 共用上述改动，保留字体预览框、主页大卡片和小图标。

删除继续调用原有批量后端，通知在处理期间使用不确定进度，结束后显示真实结果。后台处理期间可以浏览与切换页面；字体写入操作继续互斥，避免删除与应用、生成同时修改同一字体。前台服务用于正常退到后台时保活，不保证系统强停或强制杀进程后任务继续。

本地交付为 v1.3.11 / 13011 Debug 签名 APK 和内置同一 APK 的模块 ZIP。编译及包完整性检查结果见交付目录；没有自动安装或刷入手机，点击、后台删除、失败恢复和主题切换尚未手机实测。
