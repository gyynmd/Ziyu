# 字域 v1.3.5 — 本地 Debug 修复候选

- 自动挂载在外部提供者缺失/状态未知、元模块排除字域、负载发布/回执或自有排除标记处理异常、路由校验失败时尝试字域自挂载；自挂载仍需通过 PID 1 字体哈希和路由校验，失败会回滚并保留失败原因。显式挂载模式和用户设置的外部 `skip_mount` 保持生效。
- 自动回退只在当前启动影响后端；下一次启动会回收字域自己创建的排除标记并重新检测外部提供者。
- 重复应用同一字体时，通用编译先检查可复用产物。字体内容、原厂文件、设备计划、路由计划、编译代码和运行环境一致，且全部产物校验通过时复用；失配、缺失、部分生成或被改写时重新编译。
- 升级保留通用编译缓存和清单。复制优先使用硬链接；复用仍需经过当前版本的验证。
- 单批任务合并源文件、原厂文件和产物的重复 SHA-256 读取。每次仍检查路径、文件身份和读前读后变化，任务结束再次核对输入。
- 通用引擎复用相同源内容/face/容器/字重/轴的准备结果；目标处理使用独立字体对象，不共享已被其他槽位修改的对象。临时复用缓存预算为 192 MiB；超出预算的产物沿用单目标临时处理，不进入批次缓存。
- 复用同批 WOFF/WOFF2 转换，减少重复解码。
- 原厂库存有效时，先检查候选目录缓存。系统构建、启动、命名空间、挂载、后端状态、名称规则或任一子目录变化时重新探测；强制扫描与原厂恢复仍完整扫描。NoMount 的 VFS 规则不由 mountinfo 证明，因此保持重新探测。
- 保留旧 revision 2 活动产物的内容验证能力；只有新版完整缓存契约可用于跳过编译。

检查范围：修改代码的语法、Android 编译、APK 签名、模块清单和 ZIP 完整性。不自行添加或运行行为测试，不自动安装、刷入、重启或发布。实际兼容效果、资源占用与提速比例尚未手机验证。
