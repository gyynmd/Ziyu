# 字域 v1.2.28 — Debug

## 修改

- 挂载失败不改写用户偏好，不跨后端接管。元模块模式自动识别当前提供者，缺失或失败明确报错。
- 字域自挂载优先 OverlayFS，不可用时尝试 bind；Magic Mount 使用 bind。不同负载共享 ROM 实体导致别名冲突时，两者使用只读字体目录镜像 bind。单独选择 OverlayFS 时仅尝试 OverlayFS。
- 镜像保留原厂回退文件，每个私有负载条目独立覆盖同名项；复制 ROM SELinux 上下文，发布前核对负载，挂载后验证 PID 1 内容。失败按事务账本回滚，不能确认清理时保留失败证据。
- 镜像额外占用 /data 空间，约为字体目录及负载副本大小，事务失败或清理后释放。未使用全量字体 tmpfs，未写入系统分区。
- 挂载选择保存成功后询问是否重启验证，可立即重启或稍后重启；临时 Root 引导 KernelSU 软重启。
- 首页启动和刷新时读取真实偏好，未完成读取时显示读取中，不把初始 auto 值展示为实际选择。

## 升级

v1.2.26 / v1.2.27 曾将失败的自挂载偏好改为 auto。程序无法推断改写前的原始选择，升级后请在挂载设置重新选择字域自挂载，再按提示重启验证。

## 验证范围

交付报告记录静态语法检查、Debug 编译、APK 签名及模块完整性检查。没有新增或运行测试，没有安装、刷入或进行手机挂载实测；目录镜像的设备效果需要实机确认。
