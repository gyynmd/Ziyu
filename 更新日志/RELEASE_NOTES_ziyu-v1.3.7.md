# 字域 v1.3.7（本地 Debug 修复候选）

## 修正内容

- 修正 NoMount 驱动尚未加载时被记为内核不可用的问题。元模块阶段加载完成后，字域会查询实际内核接口，再验证字体是否挂载。
- NoMount 在首次挂载核验时尚未就绪，字域会在 service 阶段再检查一次；确认仍无法挂载后，自动模式尝试字域自挂载。
- 手动选择的自挂载、Magic Mount、OverlayFS 保持原模式。字体处理与现有界面流程未改动。
- 正常挂载路径不增加固定等待，继续核对字体内容、系统路由和失败回滚。

## 交付与验收

本版本为 Debug 签名 APK 及内置同一 APK 的模块 ZIP。源码修改和编译不能证明所有内核都支持 NoMount；内核驱动确实无法加载时仍需要可用的自挂载路径。

开发时只读检查了已连接手机上旧版模块：NoMount v2.0.0 的 metamount.sh 在挂载阶段加载 LKM，nm version 返回 20，而字域旧状态仍记录 nomount_kernel_usable=0。该观察证明旧状态与实际内核接口矛盾，不能作为新包手机验收。

没有自动安装、刷入或重启手机。新版挂载、软重启与视觉效果仍需设备验收。
