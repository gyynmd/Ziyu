# 字域 v1.2.31 — Debug

## OverlayFS 挂载诊断导出

- App 的完整诊断报告现在附带 `self-mount.log`、`mount-diagnostics.log`、上一份挂载诊断日志和软重启日志。
- 挂载诊断最多导出最近 1200 行并限制报告体积，保留 OverlayFS 命令、返回码及原始 stderr，便于定位内核拒绝原因。
- 第一次写入挂载环境快照时，先判断诊断日志是否存在，避免把“日志尚未创建”误报为挂载错误。
- 未改变用户选择的挂载后端和失败回滚策略。本版补齐诊断采集，不代表 PLK110 OverlayFS 挂载已修复或通过实机验证。
