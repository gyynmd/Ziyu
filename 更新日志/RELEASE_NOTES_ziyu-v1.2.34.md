# 字域 v1.2.34

- 警告保留在日志页，不单独生成未完成任务，也不改变最终应用结果。
- 设置安全页与日志页新增“忽略当前警告”，保存已忽略警告及数量；新警告继续提醒，真正的错误不会被忽略。
- 体检改用结构化日志分类，避免 WARN 行中的 failed/error 被重复计为错误。
- 日志分类优先读取显式 WARN/ERROR 级别和 JSON 外层 status；成功结果中的 warning 字段或内部重试诊断不再被当作应用错误。
- 刷写结果卡优先显示当前字体任务，历史日志不能决定当前成功或失败；已完成字体应用明确显示“字体应用成功”，实际失败显示“字体应用失败”。
- 准备完成但尚需重启的负载仍显示等待重启，避免误报当前已经生效。
- 包含 v1.2.33 的 HyperOS 字体 XML 扫描和独立 SH 共享字体分区候选查询修复。
