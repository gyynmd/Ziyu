# 字域 v1.3.3 — 本地 Debug 修复候选

- 自动识别 Vivo/iQOO、OPPO/一加/真我，选择对应的字体诊断目录；其他系统继续通用扫描。
- 诊断加入 OEM 嵌套目录、字体子目录、嵌套 XML，以及脚本和 PID 1 两种视图。使用模块 Python 时完整读取 family、TTC 索引和可变轴，支持一行多个字体定义。
- 挂载前保存可验证的原厂字体文件，避免后续编译只能看到已被替换的文件。快照与系统构建身份绑定，编译读取时验证 SHA-256；升级保留同一系统的快照。
- Vivo 兼容生成按本机清单补齐普通 UI 字体，不再只允许三个固定中文文件名；保留字重选择和原厂度量对齐，复用同一生成过程中的相同产物。
- Emoji、图标、等宽、斜体、时钟等特殊槽位及集合容器继续由既有保护和专用编译路径处理，不通过改扩展名冒充兼容。

本次只完成源码修改、语法检查、Android 编译与包完整性检查。未自动安装、刷入或执行手机行为测试，也未证明所有 172 个通用目标均可部署。新增快照须在下一次可验证原厂视图的启动阶段捕获；临时 Root 可使用已适配的 KSU 软重启流程。
