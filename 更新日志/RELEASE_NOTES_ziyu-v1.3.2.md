# 字域 v1.3.2 Debug 修复候选

相较 v1.3.0：

- 修复切换字体、恢复默认字体时，正在运行的字体与待应用字体混淆的问题。
- 修正 Mountify 软重启时旧字体层未清理的问题：按已确认来源清理旧层，再由 KSU 重新扫描、挂载新字体，保留原来的元模块模式。
- 优化交给元模块的字体文件，减少同一字体多个别名重复复制。
- 补全挂载日志导出，便于判断是负载交接失败，还是元模块仍在使用旧字体。

清理适配只在用户请求 KSU 软重启的管理器阶段执行。提供者身份、挂载来源或命名空间无法确认，或者有其他来源的挂载压在上方时，会保留待应用队列。临时 Root 不需要为此执行完整重启。

本版本是本地 Debug 候选，不是已发布正式版。编译、包完整性检查和手机验收分别记录；手机效果仍需验证。
