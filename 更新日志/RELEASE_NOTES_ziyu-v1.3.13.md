# 字域 v1.3.13（本地 Debug 手势与动效调整候选）

- 字体详情恢复下拉关闭和顶部拖动条。详情正文可正常滚动，到顶部后继续下拉即可收起；右上角关闭按钮也走收起动画。
- Material 使用自身 hide 动画；Miuix、COUI 在退出动画结束后移除底部弹层，复用弹层状态在退出后重置，关闭回调只提交一次。
- 四个主页的底栏点击统一使用 260 毫秒侧滑，松手吸附为 220 毫秒。快速改变目标时同时检查实时位置与偏移，避免只看上次停稳位置而漏掉中途返回；页面记录只在停稳并对齐时提交。
- 设置详情侧滑统一为 260 毫秒曲线，明确前后页面层次，使用三个主题各自的不透明背景及边界裁切，移除全页交叉淡入淡出造成的文字重叠。
- 字体库、组合页和组合工具的背景缩放改为同节奏、无回弹的曲线。未新增主动页面预加载、Root 调用接口或字体处理任务。

这次修改集中于 UI 手势和动效。字体生成、应用、删除、挂载及回滚的后端逻辑未修改。编译和包检查不能证明实际帧率提升；下拉、快速连续切换、反向返回及三个主题效果仍待手机验收。
