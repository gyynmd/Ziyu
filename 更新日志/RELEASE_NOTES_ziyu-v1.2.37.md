# 字域 v1.2.37

- 包含 v1.2.36 的 HyperOS 原厂槽位、动态 OEM 分区、XML 子目录引用与元模块检测兼容修复。
- 保留原厂 XML 的物理字体负载支持部分应用：无法挂载的独立字体位置保留原厂字体，其余通过实际路由与文件校验的字体继续应用；界面显示成功及未应用位置警告，用户可忽略当前警告。
- 所有自挂载立即登记到统一账本，按目录开始位置进行局部回退，消除分区账本合并前中断造成的清理遗漏。
- 回退账本原子更新，保留未清理目标；挂载归属未确认时不直接卸载。启动标记无法保存时停止提交，实际挂载前写 preparing，避免沿用旧成功状态。
- 重复检查和后续启动阶段重新读取部分字体策略，修复已部分应用的 bind 字体被再次检查误判失败的遗漏。
- 完全没有字体应用证据、源负载损坏、XML 依赖不完整及回退未确认仍保留真实失败。

本次交付为 Debug APK 与内置相同 APK 的模块 ZIP。需更新模块 ZIP 才能更新底层挂载脚本，单独更新 APK 不足以更新本次修复。编译、语法和包完整性检查不等于手机实测验收。
