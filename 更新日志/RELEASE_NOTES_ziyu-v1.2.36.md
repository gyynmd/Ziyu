# 字域 v1.2.36

- 修复 HyperOS 原厂字体槽位已被扫描却不被最终验证器接受的来源遗漏。
- 最终验证读取动态 OEM 分区名单，并统一跨分区 XML 相对子目录引用的候选路径。
- 保留 ROM XML 的物理字体负载支持部分应用：独立分区失败只回退该分区；逐文件 bind 失败跳过该目标。保留其余已验证的字体，不再因单个不可用位置回滚全部字体。
- 首页、字体刷写、设置及导出日志显示部分应用和未应用位置。用户可忽略当前警告，部分应用的事实仍保留。
- 源负载损坏、XML 改写依赖、无法确认安全回退，以及完全没有实际应用证据仍保留失败，不伪造成功。
- Meta OverlayFS 分开记录身份、声明、排除、运行文件、镜像检查条件，支持 KernelSU 提供的已挂载 MODULE_CONTENT_DIR；后续阶段只读重新检测并核对实际字体，不晚期发布、不擅自切换后端。
- 导出日志补齐当前 boot ID、分区名单、应用结果、库存槽位来源、元模块文件及字体挂载信息；警告计数沿用设置页的忽略规则。
- 包含 v1.2.35 的 OverlayFS BusyBox standalone 启动兼容修复。

本次交付为可安装 Debug APK 和内置相同 APK 的模块 ZIP。编译及打包检查不代表 Redmi/Xiaomi 手机实测验收。
