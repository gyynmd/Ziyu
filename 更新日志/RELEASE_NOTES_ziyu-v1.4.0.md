# 字域 1.4 正式版

本次以 **v1.3.0 正式版**为对比，重点完善 vivo/iQOO 字体适配，同时改进字体兼容、组合字体和日常使用体验。

## 新增与适配

- **vivo/iQOO 字体适配**：识别不同系统后分类扫描更多字体目录与字体配置，按本机实际槽位生成，不再局限于几个固定字体文件名。完善原厂字体快照的获取与保留。
- **组合字体微调**：可分别调整英文、数字的大小和上下位置，改善中英数字搭配；字体详情可查看组合来源。
- **三套主题完善**：Material、Miuix、COUI 使用各自的主题与控件，字体示例增加突出预览框，首页联系入口更清楚。

## 修复

- 修正 NoMount 驱动加载前被误判不可用的情况，完善自动模式的挂载确认与自挂载回退。
- 完善临时 Root 的软重启字体交接，修正待应用字体与当前字体混淆、旧字体层未正确更新等问题。
- 改进字体兼容检查和组合源字体检查，减少“缺少原厂快照”“明明有 head 表却提示缺少”等情况。
- 字体详情支持下拉关闭，收起动画完成后再退出；改进快速连续切换页面的衔接。
- 删除字体后立即更新列表，后台完成真实删除；失败会恢复对应字体显示。

## 优化

- 复用已验证的字体缓存和同批准备结果，减少重复转换、实例化、哈希与复制。
- 原厂字体模板按需读取，避免没有必要的名称索引和整份字体读取。
- 合并挂载状态读取，完善挂载详情、待重启状态及日志导出。
- 历史更新日志和开发文档留在 GitHub，模块只携带运行文件、简短版本提示与许可证；改进压缩方式，避免说明文件随版本不断累积。

**请下载完整模块 ZIP 升级，App 已内置；正式版不单独发布 APK。** 新适配的显示效果仍与机型、系统和 Root/挂载环境有关，具体机型验收继续收集反馈。若遇到问题，请务必通过 App 首页的酷安主页或 QQ 群联系作者，并附上软件内导出的日志。
