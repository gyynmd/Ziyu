# 字域 v1.2.38

## 直接切换字体

- 修复兼容引擎已应用字体后，每次新选择仍重新进入通用编译的问题。沿用物理兼容切换路径，支持 A → B，以及重启前 B → C 的再次提交，不需要先恢复系统默认。
- 通用生产编译先检查已知无法安全消除的风险和原厂快照缺失。有目标已明确不可部署时，提前转兼容路径，不继续耗时编译其余目标；手动编译仍保留详细 Artifact 诊断。
- 通用准备默认限制为 90 秒，使用现有子进程监督器回收编译进程后再继续兼容路径。取消或清理无法确认时停止，避免旧编译器与新切换同时写入。
- 切换总超时使用设备 uptime 计时，避免每次轮询的开销累计到 7～8 分钟。任务日志增加返回码、耗时和最后阶段；后台监督器返回实际切换失败码。

## 使用与验证范围

同次开机可以连续提交，下一次完整重启使用最后一份成功提交的字体。新提交不改写当前启动正在使用的字体负载；本次没有接入上游针对其自挂载核心实现的热切换。仍需完整重启完成字体生效验收。

交付为 Debug APK 和内置同一 APK 的模块 ZIP。编译、静态语法和打包完整性检查不代表实机已验证；未自动安装或刷入。
