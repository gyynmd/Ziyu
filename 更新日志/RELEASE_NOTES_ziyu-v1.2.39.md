# 字域 v1.2.39

## 本次兼容修复

- 通用编译器复用库存扫描器的原厂字体链接解析：支持 `/system/font`、嵌套 product 等目录别名，以及原厂字体目录中的绝对和相对跨分区链接。链接只在已选择的原厂目录间解析。
- 读取自挂载 lower 前核对本次启动 ID、挂载账本和挂载表，拒绝传播未隔离或已有子挂载的目录。App 命名空间不可见时，尝试 PID 1 的目录视图；不会把当前替换字体当作原厂模板。
- 对未捕获 lower 的字体分区，只有确认目录位于只读 erofs/ext4 块设备原厂分区、没有字体目录或文件子挂载时才读取；支持链接到未替换分区的原厂字体，不开启无条件读取当前系统字体。
- 同一个物理文件的正常、斜体和不同字重 XML 引用分别选取真实源 face；物理文件样式优先使用原厂 OS/2 度量。存在斜体引用不再把整个正常字体文件判为斜体。
- 显式 XML `wght` 轴用于选择与实例化真实字重；保留原 XML 字重、样式、索引及轴属性。预检警告显示具体字重和样式，产物记录所选源 face。
- 库存扫描 revision 7 补存 `<axis>` 子节点及精确 XML 字重，并将字重、family 属性和轴值纳入引用去重键，避免同文件的多字重引用被合并丢失。旧库存按原有安全刷新流程升级，无法验证原厂视图时保留旧清单。
- 规划、路由与编译 revision 递增，旧计划与产物需重新生成。

## 范围

本次补齐原厂来源与字体引用契约的处理。源字体确实缺少所需字重或斜体、目录访问被内核或 SELinux 拒绝时，仍按已有物理兼容路径处理并保留限制信息。保持 v1.2.38 连续提交与失败恢复机制，完整重启使用最后成功提交的字体；本次未接入热切换。

交付为 Debug APK 与内置同一 APK 的模块 ZIP。编译和打包完整性检查不代表手机兼容性已经实测；未自动安装或刷入。
